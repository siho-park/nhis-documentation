    Sources and versions¶

    Every dataset page and codebook entry on this site rests on an NHIS document, and this page records which version of each is followed. When the NHIS publishes a newer document, the older one is kept here as superseded so that readers can tell which description applies to their extract.

    Conflicts between sources¶

    Where NHIS documents disagree, the site states both versions and marks the entry rather than choosing silently. The conflicts found so far are listed below.

    • Cause of death in the Senior Cohort. The Senior manual lists two cause-of-death variables, while the portal and the 2024 guide to new applications state that the database has none. See the Senior Cohort page.
    • Sampling of the Senior Cohort. The Senior manual describes stratified sampling in one section and simple random sampling in another. See the Senior Cohort page.
    • Family history in the National Sample Cohort, 2018 to 2023. The layout file codes these questions 1 and 2, while the manual text and the customized DB layout code them 0 and 1. The five variables are marked Disputed, as in Q_FHX_HTN.
    • Triglycerides in the Low-Risk Sample Dataset. The manual gives the formula for calculated LDL cholesterol under triglycerides. See the Low-Risk Sample Dataset page.
    • Requestable years for the customized DB. The 2024 guide allows requests through 2023, and the 2026 application form allows requests through 2024. The site follows the 2026 form.

    Corrections in the codebook¶

    The layout files and manuals are written to be read as printed tables, so a few cells do not survive a mechanical import. The importer corrects the cases below, and each affected variable page carries a note that describes the correction.

    • Admission route. The cohort manuals list the two digits of the admission route separately, and the codebook lists the combined codes 11 to 32 with the labels of the customized DB layout, as in HSPTZ_PATH_TYPE.
    • Shared description cells. In the 2018 to 2023 screening layout of the National Sample Cohort, one description cell spans several rows, such as the unit and missing-value rule of six blood tests. The description is applied to every row it spans, as in G1E_VA_LT.
    • Year markers. Notes such as 2018년 or 2019부터 적용 next to a code list are applied to the years of the entry, and a cell that lists two code sets for different years is split into two periods.
    • Codes outside their row. The codes of the 2002 to 2008 past-history questions in the National Sample Cohort sit in one shared note, and they are attached to each of the nine variables.
    • Codes that do not apply. The layout repeats yes and no codes for the free-text field Q_AWR_DZ, and these are omitted.
    • Duplicate codes. Six variables list one code with two meanings in the same years, as in GOE_JDG. These are reproduced as printed with a note, since the documents give no way to tell which meaning applies.

    The importer does not invent codes the documents leave out. The long-term care assessment items (T02) of the National Sample Cohort and the Senior Cohort, for example, refer to the response categories of the assessment form printed in the manual, and their numeric codes are not documented.

    1. The manual refers to the national statistics agency as 국가데이터처, the name that Statistics Korea took in October 2025, so it was written after that date. ↩
