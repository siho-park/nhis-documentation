    Low-Risk Sample Dataset (저위험 표본데이터셋)¶

    This page lists all 37 variables of the Low-Risk Sample Dataset in 2 tables, as described in the NHIS documentation listed below. Select a variable to see its Korean and English names, its description, and the meaning of each code.

    Background on sampling, versions, and linkage is on the dataset page.

    Sources

    • Low-risk sample dataset manual (저위험 표본데이터셋 매뉴얼.hwp)
