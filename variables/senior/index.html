    Senior Cohort (노인코호트DB)¶

    This page lists all 391 variables of the Senior Cohort in 11 tables, as described in the NHIS documentation listed below. Select a variable to see its Korean and English names, its description, and the meaning of each code.

    Background on sampling, versions, and linkage is on the dataset page.

    • Senior cohort manual, v1.4 (노인코호트DB 매뉴얼v1.4.hwp)
