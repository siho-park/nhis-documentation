# Working with the data

These guides cover the tasks that almost every project with NHIS data has to solve, and the mistakes that are easy to make along the way. The examples use the variable names of the [National Sample Cohort 2.2](../variables/nsc/index.md), and the logic carries over to the other databases, whose names for the same fields are listed in the [variable name crosswalk](../datasets/index.md).

- [How the tables fit together](table-structure.md) explains the identifiers that link eligibility, claims, screening, and provider records.
- [Constructing an analysis sample](sample-construction.md) walks through building a person-year panel.
- [Identifying conditions](identifying-conditions.md) covers diagnosis-based definitions of disease.
- [Utilization and spending](utilization-spending.md) covers counting visits and admissions and measuring costs.
- [Code examples](code-examples.md) collects short snippets in Stata, SAS, and R.
